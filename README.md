## How to Use

1. Extract the zip file.
2. Open `index.html` in any modern browser (Chrome, Firefox, Edge).
3. Click on the three cards to navigate to:
   - HTML Programs
   - CSS Programs
   - JavaScript Programs
4. Each program opens as a separate page with working demonstration.
5. Use the **Home** and **Back to Programs** links on every page for navigation.
